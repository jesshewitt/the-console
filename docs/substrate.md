# Substrate

The worldview the new divination system rests on. Internal design document. Phase 4 (writing the 72 entries) draws from this directly; if you can't derive an entry from this substrate, the substrate has a gap.

## 1. What this system is for

The system offers a fresh description of the consulter's situation. When habitual thinking has stalled, an unfamiliar framing of the moment can open a path that wasn't visible before. The primary offer is attitude adjustment - not through instruction, but through the image itself. The consulter sits with the description and applies it; the system does not direct them.

Two quieter functions run alongside the surface offer:
- *Transformation*: sustained engagement with the symbols does cumulative work over time, even when the immediate use is reframing.
- *Character building*: repeated use shapes who the consulter is becoming, even though no single reading names that explicitly.

Neither is the stated goal; both are real.

What this rules out at the structural level: direct prediction, prescriptive instruction, coaching voice, any framing that positions the system as authoritative about the consulter's specific situation.

Take the casting seriously enough to make it work. Don't require metaphysical commitment to the casting being "really" meaningful in any cosmic sense. The reading lands as a useful prompt because the consulter brings attention to it; whether that attention encounters something real outside the consulter is a question the system doesn't claim to answer.

This is the chaos-magic both/and: the act is treated as live without depending on belief. A consulter who reads the system as random prompt + framework gets value from it. A consulter who reads it as something more gets value too. The system is built so neither stance breaks it.

## 8. Style guide

Conventions for writing the 72 entries (8 trigram entries + 64 hexagram entries) in Phase 4.

**Voice: thoughtful friend.** Plain, present-tense language. Not a scholar, not an oracle, not a coach. Someone who has spent real time with the system and is telling the consulter what they see. No academic hedging, no mystical pronouncement, no coaching imperatives.

**Image-grounded.** Every entry centers on a concrete situation or image, not an abstract claim. Avoid pure-abstract entries like "harmony arises from yielding." If the entry doesn't have a concrete picture in it, redraft.

**No jargon.** None of: systems-theory terms (attractor, feedback, entropy), mystical terms (synchronicity, archetype, vibration), academic hedges, AI-jargon. The substrate may quietly draw from these; the surface speaks plainly.

**Coherence with substrate.** Every entry is derivable from this document. The eight forces' meanings show up consistently across the 64 hexagrams. A reader who hasn't read the substrate can still use the entries cold; a reader who has sees how each entry expresses the same underlying logic.

**Approachable cold.** No required background - no I Ching knowledge, no chaos-magic familiarity, no philosophical frame. Someone landing on a single hexagram entry from a search result should be able to use it without context.
